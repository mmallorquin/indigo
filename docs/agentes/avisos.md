Acá llegan los avisos de la fábrica de piezas y las propuestas de mejora. GitHub te avisa por mail y en la app del celular.

- **Cuando corre la fábrica** (Actions → fabrica → Run workflow): aviso al empezar y al terminar, con el resumen, el costo y dónde están las piezas.
- **Cada lunes** (o a mano: Actions → mejora-semanal → Run workflow): el analista propone 3 mejoras a partir de los resultados y de lo que escribas acá.
- **Para pedir un cambio**: respondé con `@claude` y lo que querés, por ejemplo `@claude implementá la mejora 2` o `@claude el precio se lee chico en las stories`. El agente lo programa y abre un PR. Nada se aplica hasta que lo apruebes.

Nada se publica en redes ni se le escribe a clientas automáticamente.
